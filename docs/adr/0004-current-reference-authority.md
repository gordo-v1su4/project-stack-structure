# ADR-0004: Separate generation provenance from current reference authority

**Status:** accepted design (2026-11-07); live acceptance remains outstanding
**Authority:** [V1S-443](https://linear.app/v1su4/issue/V1S-443), [V1S-444](https://linear.app/v1su4/issue/V1S-444), and Robert's approved sharper Diego sheet

Replacing an approved character sheet must preserve the useful cut without claiming that older takes were generated from the new image. Keep generation references, policies, jobs and proofs immutable; append an explicit reference-replacement receipt and separate exact-frame current-reference assessments. This retains auditable history and accepted arrangement while making affected candidates visibly pending until unchanged technical gates and renewed creative review permit use.

Rewriting historical references would misrepresent provenance; blanket regeneration would discard potentially useful performances and delay the film. Ordinary story reconfirmation also changes eligibility and is not a substitute for the narrow same-character replacement. Legacy projects may bootstrap only from their verified historical certificate, owned jobs and exact original reference bytes; never invent a predecessor receipt. Evaluation success is provisional evidence, not creative approval, and final review/export independently bind the current authority and exact reviewed cut.

Implementation and verification details: [current-reference migration](../plans/2026-11-07-current-reference-identity-migration.md). This decision extends ADR-0003's exact-review requirement; it does not weaken ADR-0002's identity authority or authorize a different story, role, source arrangement or identity threshold.
