# Reviewed animatic into motion and the final cut

The full-song still plan has exact frame windows independent of the older edit
items. Video admission still validates the old windows, so a cross-item animatic
shot cannot be submitted as though it were a legacy target. Replacing the old
edit plan would also invalidate the still context and its review.

Keep the old project plan and still receipts intact. Add an explicit
`animaticMotion` request binding to the current complete animatic review, shot
binding and reviewed image hash. The saved shot supplies section, exact song
window and reference order. The request supplies a separately reviewable motion
direction and independent bounded generation intent. Legacy requests retain
their exact serialization and recovery behavior.

For reference-mode H3, freeze the reviewed sharp still as a composition input
alongside the original named identity/environment references. The still controls
composition and scene state; it does not replace named identity authority. Pin
its immutable storage version and compare full bytes with its reviewed SHA.
This mode does not claim an exact frame-zero anchor. I2VA continues to require
the exact native artifact already registered by the reviewed still, its explicit
profile and appropriate actual first-frame screen; never
silently downgrade an I2VA request into Ref2VA.

Both public admission and the worker validate the current human review and the
exact canonical completed still job, rebuilding its descriptor and RAW bindings.
Missing, foreign, altered or stale proofs fail before inference. Ordinary receipt
saves preserve review identity. Pending approval is an explicit block. The older
three-moment scene gate remains intact for legacy requests; an animatic request
uses its own reviewed full-song evidence rather than inventing those approvals.

The adapter derives legacy provenance only for existing story/source/reference
checks, then restores the full saved animatic window. The generated job ID binds
the original motion request, reviewed image and exact ordered references. Do not
mutate the legacy edit plan, auto-approve outputs, or dispatch all shots blindly.
Existing H3 duration lattice can exceed short cut lengths; show that budget and
prefer suitable existing footage before requesting new clips.
An updated full-song review invalidates unsubmitted requests. Completed historical
takes remain intact and can enter a new cut only through explicit current
target/trim review with the existing immutable reuse-origin evidence; a changed
review is not a reason to regenerate all otherwise useful footage.

Remaining end-to-end integration must project these exact targets into candidate
selection, preview and the export validator without changing their generation
context. Retained still frames identify existing source footage candidates, not
an automatic choice of source trim. Use actual decoded clip duration, exact
musical windows and continuity review before adoption. Named-lead rear views
cannot claim a frontal screen; identity-free cuts use truthful no-named-identity
evidence. Motion, draft selection and final export retain separate human review.

Acceptance: cross-old-cut video targets retain exact frame windows; legacy jobs
remain byte compatible; no-review/changed-master/changed-image/foreign or
noncanonical still requests fail before provider access; worker revalidation
matches public admission; the actual reviewed still bytes reach reference-mode
conditioning with the right role. Then prove bounded submission/recovery,
durable generated media, exact target draft selection, prepared whole-song
playback and accepted durable MP4 through the published app. Local tests alone
do not establish production generation or film acceptance.
